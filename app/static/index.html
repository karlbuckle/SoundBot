Quick start

Features

What the soundboard can do and how to use each part.

01

Sound library

Play audio files organised into one or more folders.

  1. Add a supported audio file to a configured folder.
  2. Open Sounds and refresh the library.
  3. Choose a server and voice channel, then click the sound.
02

YouTube audio

Stream the audio track from a YouTube link.

  1. Open YouTube and paste a video URL.
  2. Choose the Discord destination.
  3. Select Play in Discord. FFmpeg and Node.js must be available.
03

Discord commands

Let Discord members play clips without opening the website.

  1. Join a voice channel.
  2. Type /soundboard play and select a sound. Add volume or normalize to override the server defaults.
  3. Use stop or leave commands to control playback.
04

Multiple collections

Group clips by configuring several folders.

  1. Add each path to AUDIO_DIRECTORIES.
  2. Separate paths with commas.
  3. The folder name appears as the collection.
●

Voice clips

Save the last minute of voice chat (requires ENABLE_RECORDING=true).

  1. Choose a server and voice channel, open Clips and start recording.
  2. Press Save last minute in the top bar, or type /soundboard clip in Discord.
  3. Play or download clips from the Clips page.
05

Access protection

Protect web controls with the optional API key.

  1. Set WEB_API_TOKEN.
  2. Open the gear button in the web UI.
  3. Enter the same key for this session.
06

Usage analytics

See popular sounds, users, methods, and recent activity.

  1. Set your browser display name on Stats.
  2. Play sounds from web or Discord.
  3. Return to Stats and refresh.
07

Component health

Check whether the runtime and playback tools are ready.

  1. Open Components.
  2. Review status and version details.
  3. Resolve unavailable tools only when needed.
08

Local exploration

Explore without Docker or Discord connectivity.

  1. Run run-local.cmd.
  2. The tests run and the browser opens.
  3. Press Ctrl+C when finished.
